# Model source exports

These files are extracted from the supplied PBIX for review and documentation. `measures.dax` contains all 15 explicit measures. `power-query/` contains the two original M expressions, including their local CSV paths.

They are reference exports, not a complete Power BI Project (PBIP) and not a separate executable report. The binary PBIX remains the report artifact. Intermediate M steps include columns that are later removed; inspect the final expression before treating a discarded intermediate step as part of the final output.
